# Информация о текстурах ShippingResultScreen

## Файлы текстур:

Все текстуры находятся в `src/main/resources/assets/stardew/textures/gui/shipping/`

### 1. `scroll.png` (158x18)
- Свиток с датой, отображается сверху экрана
- Используется для показа даты вчерашнего дня

### 2. `plate.png` (128x26 или 128x156)
- Плашки категорий
- **Вариант 1**: Файл содержит все 6 плашек вертикально (128x156 пикселей)
  - Плашка 0 (Farming): Y=0-25
  - Плашка 1 (Foraging): Y=26-51
  - Плашка 2 (Fishing): Y=52-77
  - Плашка 3 (Mining): Y=78-103
  - Плашка 4 (Other): Y=104-129
  - Плашка 5 (Total): Y=130-155
- **Вариант 2**: Файл содержит только одну плашку (128x26 пикселей)
  - В этом случае нужно изменить код: заменить `plateTexY` на `0` (убрать `i * CATEGORY_PLATE_HEIGHT`)

### 3. `slot.png` (24x24)
- Иконка слота для превью предмета
- Отображается справа от плашек

### 4. `ok.png` (16x16)
- Кнопка OK
- Масштабируется до 64x64 при отображении (масштаб 4x)
- Содержит одно состояние (hover эффект можно сделать через изменение цвета или создать отдельный файл)

## Расположение на экране:

```
┌─────────────────────────────────────┐
│        [Свиток с датой]             │  ← scroll.png (158x18)
│                                     │
│        31px отступ                  │
│                                     │
│ [Plate1][Plate2]...[Plate6] [Slot] │  ← plate.png (128x26 каждая)
│                                     │     slot.png (24x24)
│                                     │
│                              [OK]   │  ← ok.png (16x16 → 64x64)
└─────────────────────────────────────┘
```

## Примечания:

- Плашки отображаются горизонтально с отступом 1 пиксель между ними
- Slot отображается справа от плашек через 1 пиксель
- Кнопка OK отображается справа от slot
- Все элементы центрируются на экране
