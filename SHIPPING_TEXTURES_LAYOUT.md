# Расположение текстур для ShippingResultScreen

## Отдельные файлы текстур:

- `scroll.png` - Свиток с датой (158x18)
- `plate.png` - Плашка категории (128x26) - одна текстура для всех плашек
- `slot.png` - Иконка слота для превью предмета (24x24)
- `ok.png` - Кнопка OK (16x16) - содержит два состояния: обычное (X=0) и hover (X=16)
- `digits.png` - Цифры для отображения денег (из `textures/gui/clock/digits.png`, размер каждой цифры 5x8)

## Расположение на экране:

1. **Свиток** (`scroll.png`) - по центру сверху
2. **Под свитком** - 31 пиксель отступа
3. **6 плашек** (`plate.png`) - вертикально в колонну с отступом 1 пиксель между ними:
   - Farming
   - Foraging
   - Fishing
   - Mining
   - Other
   - Total (с разделительной линией перед ней)
4. **Справа от плашек** - через 1 пиксель окно slot (`slot.png`, 24x24)
5. **Кнопка OK** (`ok.png`) - справа от slot, масштабируется 4x (16x16 → 64x64)

## Размеры элементов:

| Элемент | Ширина | Высота | Файл |
|---------|--------|--------|------|
| Свиток даты | 158 | 18 | scroll.png |
| Плашка категории | 128 | 26 | plate.png |
| Иконка слота | 24 | 24 | slot.png |
| Кнопка OK | 16 | 16 | ok.png |
| Цифра | 5 | 8 | digits.png (из clock) |

## Позиционирование чисел внутри плашки:

- Числа отображаются справа налево, начиная от позиции **104x, 17y** (относительно плашки)
- Используется текстура `digits.png` из clock UI
- Цифры расположены вертикально в текстуре (0 внизу, 9 вверху)

## Масштабирование:

- Кнопка OK: исходный размер 16x16, отображается как 64x64 (масштаб 4x)

## Примечания:

1. Все плашки используют одну текстуру `plate.png`
2. Иконка слота используется справа от плашек для показа превью первого предмета
3. Кнопка OK имеет два состояния: обычное (X=0) и hover (X=16) в одной текстуре
4. Общая ширина конструкции: 128 (плашка) + 1 (отступ) + 24 (slot) = 153 пикселя (центрируется на экране)
5. Общая высота конструкции: 6*26 + 5*1 = 161 пиксель
