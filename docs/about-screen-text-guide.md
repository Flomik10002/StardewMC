# Гайд: как писать текст для информационного экрана ("?")

Этот файл описывает разметку, которую понимает `StardewAboutScreen`
(чёрное окно, открывается кнопкой "?" на главном меню). Разметка — кастомная,
НЕ настоящий Markdown: поддерживаются только правила ниже, больше ничего.
Если в тексте попадётся что-то за пределами этого списка (`# заголовок`,
`` `code` ``, таблицы и т.п.) — оно просто останется как обычный текст, никак
не отформатируется.

Сейчас реальный текст ещё не подключён — экран показывает текст-заглушку
прямо в коде (`StardewAboutScreen.PLACEHOLDER_TEXT`). Когда файл с текстом
будет готов по этому гайду, его нужно будет подключить как источник вместо
заглушки — сам механизм чтения файла ещё не реализован, это отдельный шаг.

## Правило 1 — жирный текст: `**текст**`

```
Обычный текст, а тут **жирная часть**, а тут снова обычный.
```

## Правило 2 — курсив: `_текст_`

```
Обычный текст, а тут _курсивная часть_, а тут снова обычный.
```

Одинарная звёздочка (`*текст*`) для курсива НЕ используется — звёздочка уже
занята маркером пункта списка (правило 5), поэтому курсив на подчёркивании.

## Правило 3 — зачёркнутый текст: `~~текст~~`

```
Было ~~дорого~~, стало дёшево.
```

## Правило 4 — ссылка: `[текст](url)`

```
Подробнее на [GitHub](https://github.com/пример).
```

Ссылка кликабельна по-настоящему: при клике открывается системный браузер —
ровно так же, как обычная ссылка в чате Minecraft (с тем же подтверждающим
окном и уважением игровой настройки "chat links", если игрок её выключил —
ссылка просто не откроется). При наведении показывается всплывающая
подсказка с самим URL.

## Общее ограничение правил 1-4

`**...**`, `_..._`, `~~...~~` и `[...](...)` должны целиком помещаться в
**одной и той же строке исходного файла** — ни один из этих кусков не может
начаться на одной строке, а закончиться на следующей.

## Правило 5 — пункт списка: `* текст` (звёздочка в начале строки)

Строка, которая НАЧИНАЕТСЯ со звёздочки и пробела, становится пунктом списка
(звёздочка заменяется на "•"):

```
* Первый пункт
* Второй пункт
* Пункт тоже может быть **жирным** частично
```

Важно: звёздочка должна стоять **в самом начале строки** (пробелы перед ней
не считаются) и сразу после неё — пробел. `*текст` без пробела или звёздочка
посреди строки к списку не относятся и останутся как есть. Внутри пункта
списка остальные правила (жирный/курсив/зачёркнутый/ссылка) работают как
обычно.

## Как ЭТО работает дальше (то, что нужно знать при написании)

- **Перенос строк по ширине — автоматический.** Не нужно вручную обрывать
  длинные предложения — экран сам переносит слова по ширине окна. Разрывать
  строку самому имеет смысл только там, где нужен НАСТОЯЩИЙ разрыв (конец
  абзаца, отдельный пункт списка).
- **Пустая строка = отступ между абзацами.** Просто оставьте пустую строку
  между смысловыми блоками — она сохранится как видимый зазор.
- **Разбивка на страницы — тоже автоматическая.** Явного разрыва страницы
  (типа `---`) пока не существует — экран сам считает, сколько строк
  влезает по высоте окна, и режет по этому количеству. Если в будущем
  понадобится ручной разрыв страницы — это отдельная доработка, сейчас его
  нет.
- Текст перед первым пунктом списка и после последнего — обычные абзацы,
  ничего специального с ними делать не нужно.

## Мини-пример целиком

```
**StardewMC**
Небольшое вступление в свободной форме, без разметки.

* Первый пункт с описанием
* Второй пункт, где **важное слово** выделено
* Третий пункт про _курсив_ и ~~зачёркнутое~~
* Четвёртый пункт со [ссылкой](https://github.com)

Обычный абзац после списка, который спокойно переносится по ширине окна
сам по себе, сколько бы слов в нём ни было.
```
