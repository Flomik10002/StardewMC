**About the Project**

This is an independent, unofficial fan project dedicated to adapting Stardew Valley for Minecraft.

The project combines original and adapted Stardew Valley materials with code, technical systems, interfaces, 3D models, and implementations that I create specifically for Minecraft.

**Unofficial Status**

This project is not affiliated with Eric Barone / ConcernedApe, is not endorsed by him, and is not an official Stardew Valley product.

This project is also not an official product of Mojang Studios or Microsoft.

**Created Specifically for This Project**

A substantial part of this project is developed independently and specifically for Minecraft.

This work includes or may include:

* user interfaces and interaction systems
